# Hostel_Management_System
A C++ console-based hostel management system developed to practice and understand programming logic, data management, and system architecture.

## Features
menu selection process, comprising of;
- Room allocation
- Pasta order
- Burger order
- Noodles order
- Shake order
- Chicken-roll order
IT also features a display of information regarding the sales and collection made.
Exit feature also inclusive.

# Technology
C++

# How to Run
g++ hostel_management.cpp - o hostel_management
.\hostel_management
